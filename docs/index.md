# Portal Playground

Welcome to Portal Playground - a Portal-like playground game!

## Getting Started

This is a fun, interactive game inspired by the Portal video game series. Explore the playground and solve puzzles using portal mechanics.

## Features

- Interactive gameplay
- Portal mechanics
- Puzzle solving
- Fun exploration

## How to Play

1. Open the game in your web browser
2. Use the controls to navigate through the playground
3. Create portals to solve puzzles
4. Complete all challenges!

## Technologies

Built with HTML and a touch of Python for server-side functionality.
